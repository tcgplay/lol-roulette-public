CSV の追加・編集手順

コンセプトパーティーは parties フォルダの CSV で管理します。このページは人がファイルを足す・直すときの手順です。

1. ファイルの場所

index.html              … ルーレット本体（TOP）
csv-guide.html          … この手順ページ
enabled-store.js        … 抽選 ON/OFF の保存（ローカルは CSV、Pages はブラウザ）
start.bat               … ローカルサーバー起動
parties/
  config.csv            … 抽選対象の一覧と ON/OFF
  index.csv             … ファイル名の控え（任意）
  01_all_tanks.csv      … コンセプト1件につき1ファイル
  …

抽選が実際に読むのは parties/config.csv と、そこに書かれたパーティー CSV です。GitHub Pages では同じファイルを HTTPS で配ります。一覧の切替は、ローカルなら config.csv、Pages ではそのブラウザの保存領域です。

2. 新しいコンセプトを追加する

  1. 既存ファイル（例: parties/01_all_tanks.csv）をコピーする。
  2. 新しい名前にする。英数字とアンダースコアが扱いやすいです（例: 55_all_terrain.csv）。
  3. 先頭3行の # name: # concept: # playstyle: を書き換える。
  4. 5レーン分の行を書く。チャンピオンは必須。スペル・アイテム・ルーンはコンセプトを成立させる核を書く（例: 全員タンクなら心の鋼）。フルビルドや関係ない汎用指定は空欄（画面では「自由選択」）。アイテム列の並びは購入順ではない。
  5. parties/config.csv の末尾に1行追加する。
  6. （任意）parties/index.csv にも同じファイル名を足す。
  7. start.bat でサーバーを起動した状態で TOP を再読み込みし、抽選対象件数が増えていることを確認する。

config.csv の追加例:

55_all_terrain.csv,1,全員壁を作る
列意味
filenameparties フォルダ内の CSV ファイル名
enabled1 で抽選する / 0 で抽選しない（true / yes / on も可）
memo人が見て分かるメモ。抽選画面には出ません

3. 既存コンセプトを編集する

  1. 直したい parties/*.csv をテキストエディタで開く（Excel よりメモ帳や VS Code / Cursor が安全です）。
  2. 説明文だけなら # name: などを直す。編成なら該当レーンの行を直す。
  3. UTF-8 のまま保存する。Excel で保存すると文字化けすることがあります。
  4. ブラウザを再読み込みする（抽選中のデータは再読み込みで入り直します）。

抽選から外すだけなら CSV 本体はいじらず、パーティー一覧 の「抽選する」をオフにするか、config.csv の enabled を 0 にします。ローカル（start.bat）の切替は config.csv に保存されます。GitHub Pages では config.csv は変わらず、そのブラウザにだけ残ります。

4. パーティー CSV の書き方

先頭の説明（# で始まる行）

# name: 画面に出すコンセプト名
# concept: コンセプトの説明
# playstyle: 運用・進行の説明

name はルーレットの表示名です。concept と playstyle は結果画面に出ます。

ヘッダー行とメンバー行

説明の次に、次のヘッダーを1行置き、その下にレーン5行を置きます。列の順番と名前は既存ファイルと同じにしてください。

lane,champion_key,champion_name,spell1_id,spell1_name,spell2_id,spell2_name,
item1_id,item1_name, … item6_id,item6_name,
rune1_icon,rune1_name, … rune6_icon,rune6_name

（実際のファイルでは改行せず1行です。）

列内容
laneトップ / ジャングル / ミッド / ボット / サポート
champion_keyData Dragon の英語キー。画像 URL に使います（例: TahmKench MonkeyKing Khazix）
champion_name日本語名。パーティー2の重複判定はこの名前で行います
spell1_id / spell2_idコンセプトに効くスペルだけ（点火、ゴースト、フラッシュフックなど）。不要なら空欄。ジャングルのスマイトはレーン運用上入れてよい
spell1_name / spell2_name画面に出すスペル名
item1_id … item6_idコンセプト実現に必要なアイテム ID だけ。並びは購入順ではない。空欄は「自由選択」
item1_name …Data Dragon の公式なアイテム名。画面の見出しは「購入アイテム」で、番号は出ない
rune1_icon …コンセプトに必要なルーン画像パスだけ。空欄は「自由選択」
rune1_name …runesReforged.json の公式な日本語名

よく使うサモナースペル ID

SummonerFlash      フラッシュ
SummonerTeleport   テレポート
SummonerSmite      スマイト
SummonerDot        点火
SummonerHeal       ヒール
SummonerExhaust    イグゾースト
SummonerHaste      ゴースト
SummonerBarrier    バリア
SummonerBoost      クレンズ

5. 画像用 ID の調べ方

グラフィックは Riot 公式 Data Dragon だけを使います。ID やキーは次で確認できます。

  • パッチ一覧: versions.json
  • チャンピオン（キーは英語名）: https://ddragon.leagueoflegends.com/cdn/最新パッチ/data/ja_JP/champion.json
  • アイテム ID: .../cdn/最新パッチ/data/ja_JP/item.json
  • ルーン画像パス: .../cdn/最新パッチ/data/ja_JP/runesReforged.json の icon

ルーンは perk-images/ から始まるパスをそのまま rune1_icon に貼ります。アプリ側で Data Dragon の URL を付けます。

6. 書くときの注意

  • コンセプトの中心になるチャンピオンだけを入れる。「少しでも近い」では足りません。
  • スペル・アイテム・ルーンはコンセプトを成立させる核を指定する。タンクなら心の鋼、毒ならライアンドリー、長距離ならRFC / ホライゾン、のように「これがないとコンセプトにならない」ものは入れる。6スロット全部やフラッシュ固定は不要。空欄は画面で「自由選択」と出ます。
  • アイテム列は購入順ではない。部品と完成品（古いストップウォッチとゾーニャ、など）を並べない。画面にも番号は出ない。
  • アイテムはチャンピオンの攻撃力寄り・魔力寄りに合わせる。コンセプトに欲しくても、主ステータスが合わないものは空欄にする。攻撃チャンピオンにライアンドリーやリーライ、魔力チャンピオンに妖夢やヒュブリスは置かない。
  • ルーン名は Data Dragon の ja_JP/runesReforged.json にある公式名をそのまま書く。通称で置き換えない。
  • ジャングルには、キャンプを回してオブジェクトを争えるチャンピオンだけを置く。ユーミのようにジャングルが成立しないチャンピオンは置かない。
  • name は編成の狙いがすぐ分かる日本語にする。concept と playstyle も、読んで意味が通る文章にする。
  • 近いコンセプト同士でチャンピオンが被っても、ずらす必要はありません。抽選はパーティー1のチャンピオン名と1人でも重なるコンセプトを、パーティー2から丸ごと外します。CSV の中身は書き換えません。
  • 新しく足すパーティーは、既存 CSV にすでにいるチャンピオンを 3 人まで含めてよい。4 人目以降は、どのパーティーにもまだいないチャンピオンにする。既存ファイルのメンバーは直さない。連番の「同じコンセプト 2」は、そのコンセプトの既存メンバーとは 1 人も被せない。その条件で中心の 5 人がもう 1 組いるなら、連番でファイルを足す。
  • 1ファイルはレーン5行です。同じパーティー内で同じ champion_name を重複させないでください。
  • セルにカンマを含む名前は、セル全体をダブルクォートで囲みます。
  • 変更を見るには start.bat で http://127.0.0.1:8080/ を開くか、GitHub Pages の公開 URL を開きます。すでにこのアプリが起動していてもエラーにはせず、そのサーバーを止めて起動し直します。index.html を直接ダブルクリックしても CSV は読めません。別の理由で起動に失敗したときは、黒い窓に理由が残ります。
抽選対象が2件未満（enabled が1の行が足りない）だとルーレットは動きません。追加したら config.csv を忘れずに。
